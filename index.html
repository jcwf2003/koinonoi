📊 Google Sheets Backup
Data syncs to Google Sheets automatically on every save — no manual exports needed. You get 6 live sheets: Athletes, Tests, Competitions, Personal Bests, Diary, and a timestamped Backups log.
1. Open your Google Sheet → Extensions → Apps Script
2. Paste the CHK_Backup_Script.gs file (provided separately)
3. Deploy → New deployment → Web app
4. Execute as: Me · Who has access: Anyone
5. Authorise and copy the Web App URL below
